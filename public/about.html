О приложении

Учебный сервер и PWA в одном проекте

Курсометр создан для лабораторной работы №6. Он показывает фиктивные значения USD, EUR и CNY, полученные из собственного Express API.

01

Express-сервер

Маршруты отдают HTML-страницы и JSON. Параметр валюты читается через req.params.currency.

02

Клиентский интерфейс

Данные загружаются через fetch(), а список, среднее значение и SVG-график обновляются без перезагрузки.

03

Офлайн-режим

Service Worker кеширует страницы, ресурсы и ответы API для всех трёх валют после первой успешной подготовки приложения.

Пример API-запроса

Адрес можно открыть в браузере при запущенном сервере.

GET /api/rates/USD 
{
  "currency": "USD",
  "rates": [90.35, 91.1, 90.75, 92.2, 93.05, 92.6, 93.4],
  "avg": 91.92,
  "demonstration": true
}
